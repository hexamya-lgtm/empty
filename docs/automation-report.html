شما با هر پیش‌نویس چه می‌کنید

«انتشار» همان متن را در کانال می‌گذارد. «ویرایش» متن را برایتان می‌فرستد تا اصلاحش کنید و نسخه‌ی شما منتشر شود. «کوتاه‌تر» و «خودمانی‌تر» همان خبر را دوباره می‌نویسد. «رد» با یک دلیل کوتاه (تکراری، بی‌اهمیت، منبع ضعیف) ثبت می‌شود تا ایجنت دفعه‌ی بعد آن نوع را نفرستد.

برای چیزهای غیرفوری مثل آمار، میم و ترند، به جای پیام‌های تکی یک بسته‌ی روزانه می‌آید: «۸ پیشنهاد امروز» و شما چندتایش را تیک می‌زنید.

پیام کنار، یک نمونه‌ی ساختگی است که فقط شکل کار را نشان می‌دهد و خبر واقعی نیست.

قبل از ساخت

چند سؤال از شما

  1. فهرست اکانت‌های X و منابعی که داریداسم اکانت‌ها، کانال‌های تلگرامی و سایت‌هایی که الان دنبال می‌کنید، و اینکه کدام‌ها برایتان معتبرترند.
  2. پست‌ها با امضای Hesam بروند یا امضای ربات؟برای امضای خودتان، انتشار باید از حساب خودتان انجام شود؛ با امضای ربات ساده‌تر است.
  3. صف تأیید فقط برای شما باشد یا ادمین‌های دیگر هم؟عرفان، مهدی و امیر هم پست می‌گذارند؛ می‌شود یک گروه خصوصی ساخت که هر کس زودتر رسید تأیید کند.
  4. ربات‌های فعلی با چه زبانی و روی چه سروری هستند؟بهتر است ایجنت کنار Hex Agent بنشیند و از همان داده‌ی FPL و همان اتصال کانال استفاده کند.
  5. بودجه‌ی ماهانه برای X و مدل زبانی چقدر است؟این تعیین می‌کند چند اکانت پایش شود و فیلتر اولیه با کدام مدل انجام شود.
